# 1.0 — first release

First public release for Minecraft 1.21.1 / NeoForge.

- Signal Wire: face-to-face redstone wires, hanging or laid along blocks, waypoints, dye colors.
- Create schematics and Schematicannon support.
- Sable / Create Aeronautics: wires on ships, Signal Cable on Simulated ropes, lasers pass through plugs.
- Signal Typewriter: keyboard and mouse channels, Button / Lever and Speed / Joystick modes.
- Gamepad Receiver: buttons, analog sticks and triggers.
- English and Russian.
